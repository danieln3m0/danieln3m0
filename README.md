<h3><img src="https://github.com/danieln3m0/danieln3m0/raw/output-origami/tira-obras.svg" height="44" alt="作品 · Obras"></h3>

Cada repositorio está dibujado como el patrón de pliegue (展開図, *tenkaizu*) de un modelo de origami, con el método del árbol: cada archivo es una solapa (un círculo) y cada carpeta reserva una banda alrededor de sus archivos (un río). En los repos grandes se dibuja una muestra de hasta 30 solapas. Es un esquema de diseño generado desde el código real, no un modelo comprobado para plegar.
