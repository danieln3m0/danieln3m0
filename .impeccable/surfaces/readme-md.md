## Direction contract

THESIS: The profile is a folder of origami crease patterns (展開図). Each repo is designed as a model with the tree method: every file is a flap (circle), every folder a river band, gaps filled with rabbit-ear molecules, printed in Yoshizawa–Randlett notation. Refuses the badge wall, stat cards and the generic "Japanese" costume of cherry blossoms and rising-sun rays.

OWN-WORLD: Two-sided kami: indigo (#1E3A5F) colored face with tone-on-tone asanoha as the field, washi white (#F5F4EF) reverse as the drawing surface, indigo ink for creases; vermilion (#C8371F) only for hanko seals in hakubun. Zen Kaku Gothic New (500/900) for text, Shippori Mincho B1 for seal and section kanji. Folded corners reveal the patterned face; kirigami strips with hishi cut-outs title the sections.

STORY: The visitor sees a folded sheet with a dense crease pattern and a name, reads the legend (valley, mountain, circle = file, band = repo), opens a work, and leaves knowing he is a full-stack dev from Lima who ships at hackathons (二位, 2.º puesto Gemma 2026).

FIRST VIEWPORT: Full README width, indigo asanoha field; left two thirds a washi square tilted −2° carrying the account's crease pattern (each band a repo), top-right corner folded with a Yoshizawa valley-fold arrow, the ダニエル hanko on its lower-left corner; right column «FRANCIS DANIEL / MAMANI SILVA» as the largest type, roles, the 二位 seal with its translation, the notation legend. Directly below: intro line and four folded paper link tabs as the primary actions.

FORM: Pinned by the user (origami, «Patrones de pliegue»; extras washi/chiyogami, hanko, kirigami, Japanese labels with translation); no concept-seed roll, per the pinned-direction rule. Signature interaction: crease patterns regenerate from live repo trees on every Action run; contributions render as a square-twist tessellation, one twist per week, more twist = more contributions.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
